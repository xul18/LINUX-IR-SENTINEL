使用说明与安全边界

01

启动与接入

双击 start.bat（Windows）或执行 ./start.sh（Linux/macOS），脚本会自动安装 paramiko、启动本地服务并打开控制台。也可手动执行 python server.py。

填入目标 IP、SSH 端口、账号、口令后点击右上角「⚡ 启动排查」。账号非 root 时，连接成功后立即执行 sudo -i 提权；若 sudo 口令与登录口令不同，可单独填写。

顶栏始终可见，不受屏幕分辨率或系统缩放影响：⚡ 启动排查 发起实机排查、◈ 演示 用内置靶机数据重放流程、■ 终止 安全停止当前任务。左侧只保留接入参数，字段区可独立滚动。

02

排查范围（55 项 / 9 模块）

目标画像 · 账号与提权 · SSH 与密钥 · 持久化后门 · 进程与网络 · 文件与痕迹 · 权限与加固 · Web 服务栈 · 日志与审计。

覆盖影子 root、空口令、公钥后门、cron/systemd/rc.local、LD_PRELOAD、SUID/capabilities、伪装内核线程矿机、勒索加密残留、反弹 Shell、WebShell、Nginx/Tomcat/MySQL/PHP 缺陷、sysctl/auditd/logrotate/口令老化基线等 CTF 高频考点。

03

安全边界

只读排查：所有远程命令均为读取/枚举类，工具不会修改目标主机；整改方案仅以文字建议呈现，需人工评估后在变更窗口执行。

凭据保护：口令仅存在于本次进程内存，不写日志、不落盘、不出现在报告与导出文件中；服务默认只监听 127.0.0.1。

04

结果存档

每条发现包含简洁的 排查方法（产出关键证据的 Linux 只读命令列表）、关键证据与整改方案，三段默认全部展开，可单独折叠。演示与加载的报告会列出该检查项的完整复现命令。

点工具栏「结果存档」即可在一个面板里完成全部操作：把当前报告写入服务端 reports/、从存档列表恢复、或导入本地 JSON 报告文件；加载后可再次筛选与导出。若页面出现黄色提示条，说明后端仍是旧版本：关闭所有旧的控制台窗口，重新运行 start.bat 后刷新本页；期间保存会自动降级为下载报告到本地。

05

结果处置建议

按 严重 → 高危 → 中危 顺序处置：先隔离网络与 C2 外联，再清除复活链（cron / systemd / 启动脚本 / ld.so.preload），随后清理落地文件、账号与公钥，最后修补入口漏洞并加固。

注意 LKM Rootkit、系统命令被替换等场景排查结果可能失真，建议取证后用静态 busybox 复核或直接重装。
